# Diagrams

Each diagram is a Mermaid source file (`.mmd`) rendered to a PNG at 2x.

The document embeds the **PNGs**, not Mermaid code fences, because a code fence
only renders on GitHub — it breaks in VS Code's preview without an extension, in
a PDF export, in Word, and in slides. The source sits beside each image so a
diagram is edited and regenerated rather than redrawn.

```bash
npm run docs:diagrams     # re-render every .mmd in this folder
```
